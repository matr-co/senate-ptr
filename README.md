# senate-ptr

US Senate Periodic Transaction Reports (STOCK Act stock trades), scraped from the public
[eFD database](https://efdsearch.senate.gov) every 2 hours by GitHub Actions into `senate_ptrs.json`.
The eFD site blocks non-US IPs, which is why this runs here. Paper filings are link-only.

Public-record data; see the eFD site's terms on permitted use.
